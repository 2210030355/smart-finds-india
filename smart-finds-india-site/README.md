# Smart Finds India website

Static website for GitHub Pages. Files: `index.html`, `privacy.html`, `style.css`.

## Publish
1. Create a **public** GitHub repository named `smart-finds-india`.
2. Upload the three site files to the repository root.
3. Go to Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. Wait for GitHub Pages to publish, then visit `https://YOUR_USERNAME.github.io/smart-finds-india/` and `/privacy.html`.
5. Before submitting to Pinterest, update `privacy.html` with a real working contact method and verify the privacy disclosures.

This is a static website, not the Telegram bot or a Pinterest API backend. Never upload `.env`, access tokens, database passwords, or secrets.
